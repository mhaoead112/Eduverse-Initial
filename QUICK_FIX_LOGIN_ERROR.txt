# Quick Fix Guide - Login Error

## The Error
```
column "name" does not exist
```

## Why It Happens
The database schema expects columns like `name`, but the code uses `username` and `fullName`.

## Quick Fix (3 Steps)

### Step 1: Apply Database Migration
Run the new migration to fix the database:
```bash
npm run db:push
```

Or manually run:
```bash
psql -U postgres -d eduverse -f migrations/0003_fix_users_schema.sql
```

### Step 2: Recreate Demo Users
The demo users won't exist after the migration. Create them:
```
POST http://localhost:3000/api/auth/create-demo-users
```

### Step 3: Login
Use these credentials:
```
Username: teacher_demo
Password: demo123

OR

Username: student_demo
Password: demo123
```

## If Still Not Working

1. **Check the migration ran:**
   ```sql
   -- In psql
   \d users  -- Should show correct columns
   ```

2. **Verify columns:**
   Should see: `username`, `full_name`, `password_hash` (not `name`, `password`)

3. **Check demo users created:**
   ```sql
   SELECT username, email FROM users;
   ```

4. **Restart the server:**
   ```bash
   npm run dev
   ```
